Adversarial Resilience Patterns
▲ Velocity Burst
Attacker makes 50+ rapid small transactions across 3 devices inside a 2-minute window — stays below per-device rate limits but creates detectable shared-IP signature.
Detection Signal
Temporal clustering within ±5-minute window catches shared velocity even when individual device thresholds are not crossed. Ring confidence elevates via payment-fingerprint overlap.
▲ Mule Network Rotation
Fraudster rotates payment destinations across synthetic KYC accounts, changing IPs via residential proxies each transaction. Same device fingerprint hash persists.
Detection Signal
Graph construction edges on device fingerprint survive IP rotation. Community detection isolates nodes whose only common link is a shared device hash; isolation-forest anomaly score flags the cluster.
▲ Slow-Burn Synthetic Fraud
Low-frequency fraud (1–2 txns/day) from synthetic accounts aged 6+ months. Designed to evade temporal velocity checks.
Detection Signal
Logistic regression model trained on account-age, MCC pattern, and payment-fingerprint reuse. Payment-fingerprint shared across >2 accounts with no legitimate co-transaction history triggers ring formation even at low velocity.
▲ Split-Amount Structuring
Large fraud split into sub-₹5000 transactions to stay below high-value monitoring thresholds. Executed by coordinated ring across 8–12 entities.
Detection Signal
Ring detector aggregates cluster-level total exposure rather than per-transaction amount. Ring nodes with shared UPI handle pattern and same device fingerprint are connected; sum of cluster transactions reveals structuring.
